Set up this controller

1. Verify local certificate trust

On the Mac, use the native hub window to export the root certificate. Transfer it directly to this device. Before trusting it, compare the operating system’s full SHA-256 fingerprint with the fingerprint in that native Mac window.

This web page cannot attest certificate trust. Never bypass a browser certificate warning. The enrollment code below is only a comparison aid.

On iPhone, install the certificate profile in Settings, then enable its trust under General → About → Certificate Trust Settings. On Android, use Settings → Security → Encryption & credentials → Install a CA certificate (names vary). On a Mac, use Keychain Access. Follow the owner’s verified setup instructions for your exact OS.

Trust applies beyond this app and port; the same private IP can exist on another network. Remove the old root when retiring this hub. An address change, issuer expiry, or lost signing key requires new trust and enrollment.

2. Install, then open the app

After certificate verification, open the exact HTTPS address shown on the Mac. Keep the Mac awake on the same network.

iPhone/iPad: Safari → Share → Add to Home Screen → Open as Web App. Android: Chrome menu → Install app or Add to Home screen. Laptop: use Chrome’s Install action or Safari’s File → Add to Dock where supported.

Open the installed app before enrollment. A normal browser tab may use different storage; enroll each required context separately during the browser gate.
